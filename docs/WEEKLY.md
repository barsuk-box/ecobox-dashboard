# Недельный обзор

Деньги и лиды: пятница–четверг, сравнение одинаковых дней соседних недель. Конец периода ограничен последней датой данных и датой среза Excel. Пропуски не равны нулю, будущие записи исключаются из недельного факта. Общий денежный итог включает все направления; регистры дополнительно показаны отдельно.

## Производства

С 15.10.2026 производственный блок использует два отдельных скриншота Каменников и РУМСа. Дата среза взята из имён файлов. Этот блок не зависит от выбранной недели денег и лидов. При обновлении сохранять предыдущие агрегаты каждой площадки для последующей динамики.

Публикуются только агрегаты видимых строк. Скриншоты с ФИО и клиентами исключены из Git. Нельзя объявлять эти суммы полным портфелем: таблицы могут продолжаться за границами изображения. Сумма заказа не равна остатку работ; для процента загрузки нужны мощности и трудоёмкость. Не складывать суммы с воронкой.

В Каменниках две верхние позиции без суммы. Регистры определены по обозначениям РСП/РЗП/РАП и РегОтоп в составе заказа. Блины отдельно не обозначены: «Нет данных», не ноль. Год плановых дат принят 2026 по именам файлов. Прошедший план не доказывает просрочку — факта отгрузки на скриншоте нет. Пустые обрезанные строки не учтены. Общий итог двух площадок не выводится: возможное пересечение заказов по агрегатам не проверяется.

## Проекты и ожидаемые оплаты — 15.10.2026

Раздел недельного обзора загружен из отдельного файла ожидаемых оплат. Порог — 300 000 ₽ включительно по сумме ожидаемых платежей проекта, порядок — от большей суммы к меньшей. Один ID проекта объединяется в одну карточку; отдельные платежи, их даты, препятствия и действия сохраняются. Одинаковые названия с разными ID не объединяются.

Текущая выборка: 14 проектов, 15 платежей, 15 064 275 ₽. Это ожидания, не фактические поступления. Относительные и приблизительные сроки не превращаются в точные даты; текст относится к срезу 15 октября. Список не зависит от выбранной недели.

Обновление: `python scripts/extract_expected_payments.py "путь.xlsx" --as-of YYYY-MM-DD`. Требуется openpyxl. Проверить заголовки A:F в строке 7 и структуру исходника до импорта. JSON содержит только проекты, прошедшие порог; исходный Excel и исключённые записи не публикуются.

Перед публикацией импорта требуется проверка безопасных названий и комментариев. Тексты препятствий и шагов в опубликованной версии сокращены до деловых статусов и действий; персональные заметки и ФИО не переносятся. Импортёр сам по себе не выполняет обезличивание.

Импорт по умолчанию сохраняет кандидат в игнорируемую папку .private; перенос в src/data/expected-payments.json выполняется после проверки и редакции комментариев.

Сравнение возможно только при наличии двух соседних периодов с одинаковыми границами дней. Отсутствующие сведения показываются как «Нет данных», без нулей и вымышленных процентов.
