# Источники и расчёты

Дата среза: 01.10.2026. Денежные данные и заявки по 30.09.2026. Excel является источником чисел; HTML demo использован только как референс состава разделов.

| Раздел | Источник | Метод |
| --- | --- | --- |
| Заявки | «Новые заявки», B:Q, строки с датами | Суммирование количества и суммы восьми направлений. R:S с итогами не суммируются повторно. |
| Основная воронка | Pipeline!A3:C8 | Текущее распределение сделок по стадиям, не конверсия когорт. |
| Дополнительные стадии | Pipeline!A10:C12 | Отдельный блок, вне основного итога. |
| Дополнение «Блины» | Pipeline!D8:E8 | 48 678 000 ₽ отдельно, не добавлено в производство автоматически. |
| Прогноз | Pipeline!A14:B16 | Три категории риска на октябрь (B13), без вымышленных вероятностей. |
| Поступления | «ПоступленияОтгрузки - месяц», B3:M9 | Исходные SUM пересчитаны, ручные значения сохранены. |
| Отгрузки | тот же лист, B14:M20 | Аналогично, без повторного суммирования итоговых строк. |
| Дневная динамика | «Поступления по дням», «Отгрузки по дням», A:H | Сумма числовых значений в каждой дате. Пустые дни не объявлены подтверждёнными нулями. |

Скрипт читает XML книги без изменения файла. Игнорируется ложный used range в 1 048 576 строк. Любая неизвестная формула вызывает ошибку. Суммы округляются до копеек при переносе. Пропуски хранятся как `null`, реальные нули — как `0`. Будущие месяцы (включая SUM пустых диапазонов) не выдаются за фактические нулевые операции.

Контрольные итоги:

- 1 587 заявок, сумма 1 480 561 931,02 ₽.
- Поступления 138 403 842,01 ₽; отгрузки 138 931 851,67 ₽.
- Основная воронка: 171 сделка, 130 651 814 ₽.
- Разница месячной сводки и дневных записей: поступления в мае +0,50 ₽, отгрузки в июне −0,50 ₽. Это сохранённые различия источника, не исправленные предположением.

Фильтр периода действует на заявки и движения денег. Воронка и прогноз всегда показывают датированный срез, поскольку истории стадий нет. Неделя начинается в понедельник; фильтр месяца применяется **до** группировки по неделям, чтобы не включать соседний месяц. CSV заявок учитывает выбранный период и ЦФО, денежный CSV содержит месячные итоги, CSV воронки — основные стадии.

Сумма заявок не равна выручке. Разница поступлений и отгрузок не равна прибыли, остатку денег или дебиторской задолженности. Прогноз не превращается в факт.
