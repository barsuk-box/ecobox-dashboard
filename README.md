# ЭкоБокс — Пульс бизнеса

React-дашборд по данным таблицы «ЭКОБОКС 2026»: заявки, ЦФО, воронка, прогноз оплат, поступления и отгрузки.

[Открыть сайт](https://barsuk-box.github.io/ecobox-dashboard/)

## Возможности

- Шесть разделов, выбор месяца, сумма/количество, группировка по дням, неделям и месяцам.
- Поиск и сортировка направлений, детализация, скачивание CSV.
- Отгрузки во всех итогах, графиках, недельных сравнениях и CSV рассчитаны без направления «блины». Исходные данные сохраняются для сверки.
- Светлая и тёмная темы с сохранением выбора. Manrope с кириллицей, без засечек и курсива.
- Авторская Blender-сцена: металлические кассеты с анимацией сборки, GLB, Three.js, параллакс и пауза.
- PNG при отключённом WebGL или reduced motion. Анимация приостанавливается вне экрана и в фоновой вкладке.
- Мобильная навигация и таблицы-карточки. Горизонтальная прокрутка страницы и выделение текста на мобильных отключены; поля ввода остаются редактируемыми.

## Недельный обзор


Раздел «Недели»: сравнение поступлений, отгрузок и лидов; регистры отдельно. Производство — отдельные срезы Каменников и РУМСа по видимым строкам скриншотов. Крупные ожидаемые оплаты загружаются отдельным файлом: проекты от 300 000 ₽ включительно, по убыванию суммы, с датами, препятствиями и следующим шагом. [Методика](docs/WEEKLY.md).

## История 2024–2026

Вкладка «История»: поступления за три года и отдельный блок РегОтоп, денежное сравнение январь–сентябрь с выбором последнего месяца; заявки и воронка РегОтоп — по август. Таблицы сохраняют все доступные месяцы. [Источники и ограничения](docs/HISTORY.md).

## Запуск

Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Локальный адрес: `http://127.0.0.1:5173/ecobox-dashboard/`.

```sh
npm test
npm run build
npm run preview
```

Браузерные тесты: запустить dev-сервер, затем `npm run test:ui`. Локальная конфигурация использует установленный Microsoft Edge. Для другой среды измените `launchOptions.channel` в `playwright.config.js`.

## Данные и ограничения

Срез на **22 октября 2026 года**, дата подтверждена владельцем для отчёта на завтра. На сайте находятся сводные бизнес-показатели, доступные всем посетителям. Исходные Excel, HTML-референс, локальные заметки и служебные файлы исключены из Git. Публикация не является системой разграничения доступа.

Это сохранённый снимок, без синхронизации с 1С/CRM. Изменение таблицы на компьютере не обновляет сайт автоматически. Заявки и отгрузки — по 21.10.2026, поступления — по 21.10. Октябрь не закрыт. Воронка и производственный отчёт — на 22.10.2026, прогноз оплат — на октябрь. Методика описана в [docs/DATA.md](docs/DATA.md) и в интерфейсе «О данных». [Сверка дополненных заявок](docs/LEADS-UPDATE.md).

При подтверждённом закрытии денежных данных добавьте к команде импорта `--complete-through 2026-09-30`, заменив дату на подтверждённую. Дата среза и месяц прогноза читаются из Pipeline; период заявок определяется по фактическим строкам.

Обновление: положить новую таблицу вне отслеживаемых файлов, выполнить `python scripts/extract_data.py "путь/к/таблице.xlsx"`, сверить изменения `src/data/dashboard.json`, обновить даты/контрольные итоги/методику при изменении структуры. Скрипт извлекает только разрешённые поля, умеет исходные формулы SUM и останавливается на неизвестной формуле. Для иной структуры нужна адаптация. После проверки — commit и push.

## 3D

Исходная сцена: `assets/ecobox-assembly.blend`. Воспроизводимый генератор: `scripts/build_blender.py` (Blender 5.2). Модель стилизованная, не является техническим чертежом продукции. 28 объектов, около 5 280 треугольников, GLB 288 КБ с анимацией. Текстуры не используются, материалы PBR.

```sh
blender --background --factory-startup --python scripts/build_blender.py
```

## Публикация

Интерактивные графики: недельные поступления, отгрузки и выпуск (4/8/12 недель), история стадий воронки с переключением суммы/количества. Точные значения доступны через выбор периода, серии переключаются легендой. История воронки хранится в `src/data/pipeline-history.json` и дополняется при импорте отчётов. Методика выпуска и ограничения расчёта незавершённого производства — в [docs/WEEKLY.md](docs/WEEKLY.md).

GitHub Actions запускает проверки, сборку и GitHub Pages после push в `main`. В настройках Pages должен быть выбран источник GitHub Actions. Приложение рассчитано на `/ecobox-dashboard/`; при смене адреса обновите `base` в `vite.config.js`.

Three.js загружается отдельным модулем после интерфейса. Его production bundle около 181 КБ gzip; Vite предупреждает о размере несжатого модуля. Секретов, API-ключей и внешних аналитических трекеров нет. Шрифты и 3D размещены локально в сборке.
